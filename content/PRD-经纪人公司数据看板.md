## 1. 背景 & 目标

### 1.1 背景说明

- **业务背景**：经纪人公司是家乐集团橙鸟租房平台的重要B端客户，通过经纪人团队为客户提供租房中介服务。公司管理层需要实时掌握整体中介费收入、销售团队表现和签约情况，以便进行资源调配和业绩管理。当前经纪人公司的经营数据分散在合同和财务系统中，缺乏统一、直观的经营看板。
- **当前问题**：
  - 管理层无法实时掌握公司中介费总收入及销售提现情况
  - 销售团队规模与开单效率数据分散，难以评估人效
  - 缺乏佣金排行榜等竞争激励手段，销售管理缺乏数据支撑
  - 新签单量和平均租期等签约表现数据无集中展示
- **影响范围**：所有使用橙鸟租房平台的经纪人公司管理员、团队经理，涉及移动端数据看板功能模块

### 1.2 目标说明

- **业务目标**：
  - 帮助管理层实时掌握中介费收入，跟踪销售提现状态（已提现 vs 未提现）
  - 提升销售团队管理效率：通过销售团队数据（人数、新增、开单率、平均开单数）辅助人力决策
  - 激发销售竞争：通过佣金排行榜排名，促进销售积极性
  - 了解签约质量：新签单量和平均租期反映业务健康度
- **产品目标**：为经纪人公司管理层提供移动端经营数据看板，以收入为核心、团队管理为支撑、排行榜为激励，实现数据驱动的销售管理

## 2. 角色定义

### 2.1 用户角色

- **核心用户**：经纪人公司管理员/老板，需掌握公司整体经营数据
- **普通用户**：团队经理/组长，需查看所辖团队的数据
- **辅助用户**：销售本人，可查看自己的业绩排名（如功能扩展）

### 2.2 系统角色

- **管理员**：拥有完整数据查看权限，可查看包括排行榜在内的全部数据
- **运营人员**：查看签约表现和团队数据，辅助运营决策
- **审核人员**：不涉及（看板为只读展示模块）

### 3.1 模块结构

| 模块 | 子模块 | 说明 |
|------|--------|------|
| 时间筛选 | 今日 / 本月 / 近30天 / 自定义 | 全局数据周期切换 |
| 中介费收入 | 中介费总收入 / 已提现金额 / 未提现金额 | 顶部英雄卡片展示 |
| 签约表现 | 新签单量 / 平均租期 | 签约活跃度与质量 |
| 销售团队 | 销售人数 / 月新增 / 开单人数 / 平均开单数 | 团队规模与效率 |
| 佣金排行榜 | 排名 / 姓名 / 团队 / 佣金 / 单数 | 销售业绩排名激励 |

### 3.2 模块说明

#### 模块A：时间筛选

- **功能描述**：提供全局数据时间范围切换，所有指标数据随筛选周期同步刷新
- **交互逻辑**：
  - 默认展示"本月"数据
  - tab选项：今日 / 本月（默认选中）/ 近30天 / 自定义
  - "自定义"tab弹出日期选择器，支持选择起止日期
  - 选中tab高亮显示（品牌色底色 + 白色文字）
- **输入/输出**：
  - 输入：用户选择的时间周期
  - 输出：所有数据指标按所选周期重新计算并展示
- **依赖关系**：所有数据模块均依赖此筛选周期

#### 模块B：中介费收入（英雄卡片）

- **功能描述**：在页面顶部以渐变品牌色英雄卡片展示最核心的收入指标
- **交互逻辑**：
  - 卡片固定首位展示，大号字体突出中介费总金额
  - 下方分割线后展示两列子指标：销售已提现金额、销售未提现金额
  - 卡片右上角有装饰性圆形背景元素（纯视觉设计）
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：中介费总收入（元）、销售已提现金额（元）、销售未提现金额（元）
- **取值规则**：
  - 中介费总收入 = 所选周期内所有成交合同的中介费佣金总和
  - 销售已提现金额 = 销售已完成提现的佣金总额
  - 销售未提现金额 = 销售已完成但尚未提现的佣金总额

#### 模块C：签约表现

- **功能描述**：展示公司整体签约活跃度与签约质量
- **交互逻辑**：
  - 2列网格布局
  - "新签单量"卡片以品牌浅色底色高亮
  - 每卡显示指标名称 + 数值 + 单位
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：新签单量（单）、平均租期（个月）
- **取值规则**：
  - 新签单量 = 所选周期内新签订合同的总单数
  - 平均租期 = 所选周期内所有新签合同的租期总和 ÷ 新签单量，保留一位小数

#### 模块D：销售团队

- **功能描述**：展示销售团队整体规模、增长及开单效率数据
- **交互逻辑**：
  - 2×2网格布局，4个指标卡片
  - "平均开单数"卡片以品牌浅色底色高亮
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：销售数量（人）、月新增销售人数（人）、开单销售人数（人）、平均开单数（单/人）
- **取值规则**：
  - 销售数量 = 公司当前在职销售总人数（截至所选周期末）
  - 月新增销售人数 = 所选周期内新入职的销售人数
  - 开单销售人数 = 所选周期内至少完成1单的销售人数
  - 平均开单数 = 所选周期内总签约单数 ÷ 开单销售人数，保留一位小数

#### 模块E：佣金排行榜

- **功能描述**：展示销售个人佣金业绩排名，激励团队竞争
- **交互逻辑**：
  - 列表形式展示，每行展示排名序号 + 姓名 + 所属团队 + 佣金金额 + 成交单数
  - 第1-3名排名序号以品牌色圆形高亮
  - 按佣金金额降序排列，最多展示前N名
  - 支持滚动查看更多排名
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：销售排名、姓名、团队、佣金（元）、单数
- **取值规则**：
  - 排名依据 = 所选周期内个人佣金总额，从高到低排序
  - 仅展示有开单记录的销售

## 4. 业务流程

### 4.1 主流程

1. 用户进入"经纪人公司数据看板"页面
2. 默认展示"本月"周期的全部数据
3. 用户自上而下浏览：中介费收入 → 签约表现 → 销售团队 → 佣金排行榜
4. 用户可通过顶部时间筛选tab切换数据周期，所有模块同步刷新
5. 用户可在佣金排行榜区域上下滑动，查看完整排名列表

### 4.2 分支流程

- **自定义时间筛选**：用户点击"自定义"tab → 弹出日期选择器 → 选择起止日期 → 确认后刷新数据
- **查看销售详情（未来扩展）**：点击排行榜中的销售姓名 → 跳转至该销售的业绩详情页
- **下拉刷新**：用户下拉页面触发数据刷新，更新所有指标

## 5. 状态流转说明

### 5.1 状态定义

| 状态 | 说明 |
|------|------|
| 加载态 | 数据请求中，展示骨架屏 |
| 正常态 | 数据加载完成，正常展示 |
| 空态 | 所选周期内无数据 |
| 错误态 | 网络异常或服务端错误 |
| 刷新态 | 下拉刷新或手动刷新中 |

### 5.2 状态流转

- 加载态 → 正常态：数据请求成功
- 加载态 → 空态：数据为空
- 加载态 → 错误态：请求失败
- 正常态 → 刷新态：用户下拉或切换时间周期
- 错误态 → 加载态：用户点击重试

### 5.3 流转规则

- 空态时展示引导文案"当前周期暂无数据"，不隐藏模块
- 错误态展示错误提示 + "重新加载"按钮
- 刷新时保留旧数据展示，不闪白
- 佣金排行榜空态：展示"当前周期暂无销售开单记录"

## 6. 规则说明

### 6.1 取值规则

| 展示项 | 说明 |
|--------|------|
| 中介费总收入 | 所选周期内所有成交合同的中介费佣金总额 |
| 销售已提现金额 | 所选周期内销售已完成提现申请的佣金总额 |
| 销售未提现金额 | 所选周期内佣金已确认但未申请提现的总额 |
| 新签单量 | 所选周期内新签订合同的总数 |
| 平均租期 | 新签合同租期的算术平均值，保留1位小数 |
| 销售数量 | 截至所选周期末公司在职销售总人数 |
| 月新增销售人数 | 所选周期内入职的销售人数 |
| 开单销售人数 | 所选周期内至少完成1单的销售人数 |
| 平均开单数 | 总签约单数 ÷ 开单销售人数，保留1位小数 |
| 佣金排名 | 按个人佣金总额降序排列 |

### 6.2 强制规则

- 时间筛选tab至少且仅有一个处于选中状态
- "本月"为首次进入的默认选中tab
- 所有金额数值以"¥"为前缀，保留两位小数
- 人数指标单位为"人"，单量指标单位为"单"
- 平均租期单位为"个月"，保留一位小数
- 佣金排行榜仅展示有开单的销售，无开单记录不展示
- 排行榜第1-3名序号图标以品牌色高亮（圆形背景）
- 英雄卡片中介费收入主数值以超大号字体突出显示

### 6.3 优先级

- 数据正确性 > 展示实时性 > 页面美观度
- 排行榜排名 > 团队数据 > 签约表现 > 收入总览（按关注度排序）

## 7. 异常处理机制

### 7.1 异常类型

- **校验异常**：自定义时间选择时，结束日期不得早于开始日期
- **状态异常**：部分数据模块请求成功、部分失败时，成功模块正常展示，失败模块显示错误状态
- **权限异常**：用户无权限查看某些销售数据时，该数据不纳入统计或展示
- **系统异常**：服务端接口超时或返回错误码

### 7.2 处理方式

| 异常类型 | 提示文案 | 是否允许重试 | 是否阻断流程 |
|----------|----------|:---:|:---:|
| 校验异常 | "结束日期不能早于开始日期" | 否 | 是（阻止查询） |
| 状态异常 | "部分数据加载失败，请稍后重试" | 是 | 否 |
| 系统异常 | "网络开小差了，请稍后重试" | 是 | 否 |
| 佣金排行榜空数据 | "当前周期暂无销售开单记录" | 否 | 否 |
| 其他模块空数据 | "当前周期暂无数据" | 否 | 否 |

## 8. 权限控制说明

### 8.1 权限模型

- **页面权限**：经纪人公司管理员及团队经理角色可访问"数据看板"页面
- **数据权限**：
  - 管理员：查看全公司所有数据
  - 团队经理：仅查看所辖团队的数据（排行榜仅显示本团队成员）
- **功能权限**：时间筛选、数据查看为通用功能

### 8.2 权限规则

- 管理员角色 + 已登录 + 账号正常 → 查看全量数据
- 团队经理角色 + 已登录 + 账号正常 → 查看本团队数据（数据权限过滤）
