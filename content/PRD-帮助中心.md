# 帮助中心 PRD

## 一、产品定位

帮助中心是面向 **租客/房东/管理员** 的自助服务入口，目标是：

- 让用户在不联系客服的情况下，快速找到常见问题的解答；
- 降低一线客服工单量；
- 提升用户对产品的信任感与满意度。

## 三、问题分类规则

 ![[问题管理-分类管理.png]]
### 3.1 分类列表（当前版本）

|分类名|图标语义|覆盖问题范围|
|---|---|---|
|全部|九宫格|展示所有分类的问题合集|
|退款售后|退回箭头|退款申请、售后投诉、金额异常|
|审核认证|打勾文件|实名认证、企业认证、资质审核|
|房源租客|房屋图标|房源信息维护、租客档案、合同管理|
|维修装修|扳手图标|报修提交、维修进度、装修申请|

### 3.2 分类管理规则

- **新增分类**：输入分类名称，选择线性图标即可添加；
    
- **删除分类**：需将该分类下所有问题全部删除；
    
- **分类顺序**：按用户配置的排序权重从小到大排列（如0则排到“全部”后面第一个），"全部"始终置首位；
    
- **最大数量**：各个端口UI 最多展示 8 个分类图标，超出部分隐藏。

## 四、问题内容管理规则

 ![[问题管理.png]]
### 4.1 问题录入标准

| 字段   | 要求                                 |
| ---- | ---------------------------------- |
| 问题标题 | 以"如何…""为什么…""在哪里…"等疑问句开头，字数 ≤ 24 字 |
| 所属分类 | 选择问题分类                             |
| 所属端口 | 选择显示问题的端口，目前可选项有：房东助手、租客端          |
| 问题详情 | 富文本框，可输入文字、图片                      |
| 补充说明 | 可选，用于适用场景说明或注意事项，字数 ≤ 100 字        |
| 所属分类 | 每条问题只属于 1 个分类                      |
 ![[问题管理-添加问题.png]]
### 4.2 问题状态

|状态|说明|
|---|---|
|已上线|正常展示给用户|
|已下线|运营操作下架，对用户不可见|

### 4.3 问题排序规则

- 默认按 **浏览量高低顺序** 排列，浏览量相同的则按**创建时间倒序**；

### 4.4 问题批量导入规则

#### 4.4.1 导入文件格式
- 支持 **.xlsx / .xls** 格式；
- 单次导入最多 **500 条**；
- 文件大小不超过 **5MB**。

#### 4.4.2 导入表头规则

| 表头字段 | 必填  | 说明                         |
| ---- | --- | -------------------------- |
| 问题标题 | 是   | 疑问句开头，字数 ≤ 24 字            |
| 所属分类 | 是   | 须与系统中已存在的分类名称完全一致          |
| 所属端口 | 是   | 填写"房东助手"或"租客端"，多个端口用英文逗号分隔 |
| 问题详情 | 是   | 纯文本或 HTML 格式               |
| 补充说明 | 否   | 字数 ≤ 100 字                 |
| 问题状态 | 否   | 填写"已上线"或"已下线"，不填默认为"已上线"   |

> **注意事项**：表头字段名称须与上表完全一致，顺序不限；不识别多余列或别名列。

#### 4.4.3 导入校验规则

| 场景 | 处理方式 |
|---|---|
| 必填字段缺失 | 该行导入失败，跳过并记录错误日志 |
| 分类名称不存在于系统中 | 该行导入失败 |
| 端口名称不在可选范围内 | 该行导入失败 |
| 字段格式错误（如权重非数字） | 该行导入失败 |
| 问题标题已存在 | 该行导入失败（标题不允许重复） |
| 文件格式不支持 | 拒绝导入，提示"请上传 .xlsx 或 .xls 文件" |
| 文件超过 5MB | 拒绝导入，提示"文件大小超过限制" |

#### 4.4.4 导入结果反馈

- 导入完成后弹窗展示导入结果：
  - **成功条数** / **失败条数**；
  - 提供「下载失败日志」按钮，日志文件包含：行号、失败原因、对应数据；
- 部分成功时，成功数据正常入库，失败数据不阻塞整体导入。

## 五、搜索规则

### 5.1 搜索范围

- 覆盖**所有已上线**问题的标题与摘要字段；
- 不搜索下线问题问题。

### 5.2 搜索逻辑

- 支持中文关键词模糊匹配；
- 无结果时展示"暂无相关问题"空状态，并引导咨询客服；
- 搜索结果不分类，按相关度排序。

### 5.3 Placeholder 文案规范

- 格式：`搜索 [关键词1]、[关键词2] 等问题`；
- 关键词选取当前热门咨询类型；
- 当前默认文案：`搜索退款、审核、维修等问题`。

## 六、底部咨询栏规则

### 6.1 展示规则

- **首页与详情页均展示**，固定在页面底部，不随内容滚动；
- 咨询栏始终可见，不可折叠或关闭。

### 6.2 文案规范

|元素|文案|
|---|---|
|主标题|没有找到答案？|
|副标题|可转人工客服继续处理|
|按钮文字|咨询客服|

### 6.3 点击行为

- 点击"咨询客服"按钮：
    - **优先**跳转至应用内在线客服（IM 会话）；
    - 若 IM 不可用（非工作时间），展示工作时间说明并提供留言入口；
    - 工作时间：工作日 9:00–18:00（服务器时间）。

## 七、权限与可见范围

|角色|帮助中心可见性|后台内容管理权限|
|---|---|---|
|租客|可见（租客端）|无|
|房东|可见（房东端）|无|
|运营/客服|可见|可编辑问题内容、管理分类、上下线问题|
|超级管理员|可见|全权限，含删除|

> 各端展示内容可根据角色配置不同分类集合。

## 八、异常与边界处理

|场景|处理方式|
|---|---|
|某分类下问题数为 0|不展示该分类 Tab（运营及时补充内容）|
|搜索结果为空|展示空状态图（"暂无相关问题"）+ 咨询客服引导|
|页面加载失败|展示错误提示 + 重试按钮|
|客服不在线|咨询栏按钮置灰，展示"当前非服务时间" + 留言入口|
|问题内容为空|不允许发布，后台表单校验拦截|
