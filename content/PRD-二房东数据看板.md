## 1. 背景 & 目标

### 1.1 背景说明

- **业务背景**：二房东（转租经营者）是家乐集团房东助手产品的核心用户群体，他们从大房东处整租房产，再分租给终端租客，经营模式涉及"收—支—利"全链条管理。当前二房东普遍通过Excel或纸笔记账，数据分散、经营状况不透明，难以发现空置风险、欠租隐患和利润波动。
- **当前问题**：
  - 收入与支出数据分散，无法实时掌握经营全貌
  - 出租率、续签率等核心效率指标无直观展示，空置风险预警缺失
  - 大房东合同到期缺乏统一提醒，存在续约断档风险
  - 欠租/未收款无集中展示，回款管理困难
- **影响范围**：所有使用房东助手APP的二房东用户，涉及移动端数据看板功能模块

### 1.2 目标说明

- **业务目标**：
  - 帮助二房东实时掌握本月整体经营状况（收入、支出、利润），提升经营决策效率
  - 降低空置率：通过出租率、着火房（空置超30天）指标，推动及时调整出租策略
  - 降低欠租风险：通过"未收/欠租"指标集中展示，促进回款跟进
  - 确保大房东合同续约不断档：通过到期预警提醒，提前安排续签
- **产品目标**：为二房东提供一站式移动端数据看板，以可视化指标为核心、数据驱动经营决策

## 2. 角色定义

### 2.1 用户角色

- **核心用户**：二房东（转租经营者），即使用房东助手APP管理出租业务的个人或小微企业主
- **普通用户**：二房东团队内部的财务/运营人员，需查看经营数据但无管理权限
- **辅助用户**：二房东的合伙人或家庭成员，需了解大致经营状况

### 2.2 系统角色

- **管理员**：拥有完整数据查看权限，可自定义时间筛选
- **运营人员**：查看统计数据，关注出租效率与到期预警
- **审核人员**：不涉及（看板为只读展示模块）

| 签约指标 | 新签数 / 续签数 / 退租数 / 合同到期 | 租约变动统计 |
| 大房东合同到期 | 30天内到期 / 最近到期 / 待续约 / 到期合同列表 | 上游合同预警 |

### 3.3 模块说明

#### 模块A：时间筛选

- **功能描述**：提供全局数据时间范围切换，所有指标数据随筛选周期同步刷新
- **交互逻辑**：
  - 默认展示"本月"数据，点击对应tab切换数据周期
  - "自定义"tab弹出日期选择器，支持选择起止日期
  - 选中tab高亮显示（品牌色底色 + 白色文字）
- **输入/输出**：
  - 输入：用户选择的时间周期
  - 输出：所有数据指标按所选周期重新计算并展示
- **依赖关系**：所有数据模块均依赖此筛选周期

#### 模块B：经营概况（汇总卡片）

- **功能描述**：在页面顶部以渐变品牌色卡片展示最核心的4个经营指标
- **交互逻辑**：
  - 卡片固定首位展示，向下滚动时随页面滚动
  - "本月总收入"为主数值，大号加粗突出显示
  - 下方三列展示：毛利润（白底高亮）、总支出、未收/欠租
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：总收入（元）、毛利润（元）、总支出（元）、未收/欠租（元）
- **取值规则**：
  - 总收入 = 租金收入 + 押金收入 + 管理费 + 水电费 + 物业费 + 其他收入
  - 毛利润 = 总收入 - 总支出
  - 总支出 = 房东租金 + 物业费 + 维修费 + 保洁费 + 家具家电 + 其他支出
  - 未收/欠租 = 已到期但租客未缴纳的租金总额

#### 模块C：收入构成

- **功能描述**：按类别展示收入明细构成，帮助二房东了解收入来源分布
- **交互逻辑**：6格网格布局，每格显示类别名称和金额
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：各收入类别及其金额

#### 模块D：支出构成

- **功能描述**：按类别展示支出明细构成，帮助二房东管控成本
- **交互逻辑**：6格网格布局，每格显示类别名称和金额
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：各支出类别及其金额

#### 模块E：出租效率

- **功能描述**：展示房源出租核心指标，包含出租率、续签率、着火房预警
- **交互逻辑**：
  - 三列布局：出租率（橙色底）、续签率（绿色底）、着火房（红色底，高警示）
  - 下方进度条直观展示出租率百分比
  - 再下方为房间状态四格：可出租 / 已租（品牌色高亮）/ 空置 / 下架
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：出租率（%）、续签率（%）、着火房（间数）、各状态房间数量
- **取值规则**：
  - 出租率 = 已租房间数 / 可出租房间数 × 100%
  - 续签率 = 续签数 / （续签数 + 新签数 - 退租数）【或按实际定义】
  - 着火房 = 空置天数超过30天的房间数
  - 可出租 = 已租 + 空置（不含下架）
  - 下架 = 房东主动下架暂不出租的房间

#### 模块F：签约指标

- **功能描述**：展示租约变动核心指标，反映业务活跃度
- **交互逻辑**：2×2网格卡片布局，每卡显示指标名称、数值和辅助说明
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：新签数、续签数、退租数、合同到期数
- **取值规则**：
  - 合同到期 = 租客合同在30天内到期的数量

#### 模块G：大房东合同到期

- **功能描述**：展示大房东（上游）合同到期预警信息
- **交互逻辑**：
  - 顶部统计行：30天内到期份数（黄色警告背景）、最近到期天数、待续约份数
  - 下方合同列表：展示具体合同名称 + 剩余天数
  - 合同列表按剩余天数升序排列，到期最近的排最前
- **输入/输出**：
  - 输入：所选时间周期
  - 输出：大房东合同到期统计及明细
- **取值规则**：
  - "30天内" = 合同截止日期在当前日期30天内的合同
  - "最近到期" = 所有未到期合同中距离当前最近的天数
  - "待续约" = 到期后尚未完成续约的合同份数
  - 剩余天数 ≤ 30 天时，剩余天数显示为警告色（品牌橙色）

## 4. 业务流程

### 4.1 主流程

1. 用户进入"数据看板"页面
2. 默认展示"本月"周期的全部数据
3. 用户自上而下浏览：经营概况 → 收入构成 → 支出构成 → 出租效率 → 签约指标 → 大房东合同到期
4. 用户可通过顶部时间筛选tab切换数据周期，所有模块同步刷新
5. 用户可点击"大房东合同到期"列表中的条目，查看对应合同详情

### 4.2 分支流程

- **自定义时间筛选**：用户点击"自定义"tab → 弹出日期选择器 → 选择起止日期 → 确认后刷新数据
- **下拉刷新**：用户下拉页面触发数据刷新，更新所有指标
- **数据加载中**：首次进入或切换周期时，页面展示骨架屏加载态

## 5. 状态流转说明

### 5.1 状态定义

| 状态 | 说明 |
|------|------|
| 加载态 | 数据请求中，展示骨架屏 |
| 正常态 | 数据加载完成，正常展示 |
| 空态 | 所选周期内无数据 |
| 错误态 | 网络异常或服务端错误 |
| 刷新态 | 下拉刷新或手动刷新中 |

### 5.2 状态流转

- 加载态 → 正常态：数据请求成功
- 加载态 → 空态：数据为空
- 加载态 → 错误态：请求失败
- 正常态 → 刷新态：用户下拉或切换时间周期
- 错误态 → 加载态：用户点击重试

### 5.3 流转规则

- 空态时展示引导文案"当前周期暂无数据"，不隐藏模块
- 错误态展示错误提示 + "重新加载"按钮
- 刷新时保留旧数据展示，不闪白

## 6. 规则说明

### 6.1 取值规则

| 展示项 | 说明 |
|--------|------|
| 本月总收入 | 所选周期内所有收入类目中已确认到账的金额总和 |
| 本月毛利润 | 总收入 - 总支出 |
| 本月总支出 | 所选周期内所有支出类目的金额总和 |
| 未收/欠租 | 已到应缴日但租客尚未缴纳的租金总额 |
| 出租率 | 已租 ÷ 可出租 × 100%，最多保留整数 |
| 续签率 | 续签合同数 ÷ 到期应续合同数 × 100% |
| 着火房 | 空置超过30天的房间数 |
| 合同到期（租客） | 租客合同到期日在30天内的合同数量 |
| 大房东合同到期统计 | 截止到所选周期末的数据快照 |

### 6.2 强制规则

- 时间筛选tab至少且仅有一个处于选中状态
- "本月"为首次进入的默认选中tab
- 所有金额数值保留两位小数
- 百分比数值取整（不保留小数）
- 合同到期天数 ≤ 30 时，数字以警告色（品牌橙）展示
- 着火房数值 > 0 时，以红色背景高亮警示

### 6.3 优先级

- 数据正确性 > 展示实时性 > 页面美观度
- 数据加载：优先展示缓存数据，后台同步刷新

## 7. 异常处理机制

### 7.1 异常类型

- **校验异常**：自定义时间选择时，结束日期不得早于开始日期
- **状态异常**：部分数据模块请求成功、部分失败时，成功模块正常展示，失败模块显示错误状态
- **权限异常**：用户无权限查看某房源数据时，该房源不纳入统计
- **系统异常**：服务端接口超时或返回错误码

### 7.2 处理方式

| 异常类型 | 提示文案 | 是否允许重试 | 是否阻断流程 |
|----------|----------|:---:|:---:|
| 校验异常 | "结束日期不能早于开始日期" | 否 | 是（阻止查询） |
| 状态异常 | "部分数据加载失败，请稍后重试" | 是 | 否 |
| 系统异常 | "网络开小差了，请稍后重试" | 是 | 否 |
| 空数据 | "当前周期暂无数据" | 否 | 否 |

## 8. 权限控制说明

### 8.1 权限模型

- **页面权限**：所有已登录的二房东用户均可访问"数据看板"页面
- **数据权限**：用户仅能看到自己名下房源/合同的数据
- **功能权限**：时间筛选、数据查看为通用功能，无需特殊授权

### 8.2 权限规则

- 角色（二房东）+ 条件（已登录、账号正常）+ 动作（查看、筛选）
